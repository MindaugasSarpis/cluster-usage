Gluon cluster usage

Who uses the gluon node of the mathematica Slurm cluster, per anonymised user. Users are shown as letters; other users groups everyone outside the six largest, and system covers root, daemons and service accounts.

Memory per user

Average resident memory (RSS) of each user's processes, in GiB. Shared pages count once per process, so this overstates memory for programs that share a lot.

Load against cores in use

Cores in use is CPU time actually burned. Load average also counts tasks waiting on disk or NFS, which is why it sits far above the cores in use here.
